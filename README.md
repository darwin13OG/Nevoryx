# NEVORYX | Entretenimiento Digital Premium 🚀

![Status](https://img.shields.io/badge/Status-Functional-brightgreen)
![Tech](https://img.shields.io/badge/Tech-Supabase%20%7C%20Tailwind%20%7C%20JS-blue)

NEVORYX es una plataforma web de alto rendimiento diseñada para la comercialización de servicios digitales y suscripciones. Enfocada en la **experiencia de usuario (UX)** y la **atención preferencial**, esta aplicación conecta de forma directa al cliente con el administrador a través de un flujo de compra optimizado.

---

## 💎 Características Principales

- **🔄 Sincronización en Tiempo Real:** Integración con **Supabase DB** para la gestión de productos y stock.
- **⚡ Flujo de Compra en 2 Pasos:** Diseño psicológico para asegurar que el cliente realice el pago antes de confirmar el pedido.
- **🎨 Interfaz Adaptativa (UI):** Soporte completo para **Modo Oscuro/Claro** y diseño 100% responsivo para móviles y PC.
- **🛡️ Panel Administrativo Seguro:** Acceso restringido para el control de inventario, precios y duración de membresías.
- **🌑 Skeleton Loaders:** Experiencia de carga fluida para evitar pantallas vacías durante la sincronización de datos.
- **💬 Soporte Directo:** Integración con WhatsApp para despacho inmediato y soporte VIP.

---

## 🛠️ Stack Tecnológico

*   **Frontend:** HTML5, CSS3 (Tailwind CSS).
*   **Lógica:** JavaScript (Vanilla JS).
*   **Backend:** Supabase (Database & API).
*   **Iconografía:** Font Awesome 6.

---

## 🚀 Cómo utilizar este proyecto

1.  **Configuración de DB:** Es necesario contar con una tabla en Supabase llamada `products` con las siguientes columnas:
    *   `name` (text)
    *   `price` (text)
    *   `duration` (text)
    *   `stock` (int4)
    *   `image` (text)
2.  **Ejecución:** Simplemente clona el repositorio y abre el archivo `index.html` en cualquier navegador moderno.
